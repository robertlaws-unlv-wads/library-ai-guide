About this module

What this is, who made it, how it handles your data, and how to tell us when something is wrong with it.

Purpose and scope

A self-paced introduction to using generative AI carefully, for UNLV students and staff. It is deliberately one module rather than two tracks: the situations differ between coursework and library service work, but the underlying judgment is the same, and each audience benefits from seeing the other's position.

It does not cover AI for writing code, research data management, IRB and human-subjects questions, grant writing, or accessibility accommodations. It does not override any syllabus, instructor, or supervisor.

For conceptual background — what machine learning is, how the field developed — see the Libraries' AI 101 guide. This module is the applied companion to it.

Privacy

This site does not collect anything. Specifically:

  • No accounts and no logins. Nothing identifies you.
  • No analytics. No Google Analytics, no tracking pixels, no event logging.
  • No cookies, no local storage, no session storage. The site writes nothing to your browser.
  • No third-party requests. No fonts from Google, no scripts from a CDN, no embedded media. Every file the page loads comes from this site.
  • Quiz results exist only in your browser's memory and are gone when you close the tab. They are never transmitted, and we have no way to recover them.

You do not have to take our word for any of this. Open your browser's developer tools, look at the Network tab for third-party requests and the Application tab for stored data, and you will find both empty. We chose the slightly harder technical path — no web fonts, no framework, no build tooling — specifically so that claim would be checkable rather than just asserted.

GitHub, which hosts this site, records server logs including IP addresses, as any web host does. That is outside our control and is covered by GitHub's privacy statement.

Accessibility statement

UNLV University Libraries is committed to making this module usable by everyone.

Conformance target. Web Content Accessibility Guidelines (WCAG) 2.1 Level AA. As a public entity, UNLV is subject to the ADA Title II web accessibility rule, which names this standard.

How it was evaluated. Automated testing with axe DevTools and WAVE; manual keyboard-only testing of every page and every interactive exercise; screen reader testing with VoiceOver on Safari; verification at 320 pixel width and 400% zoom; contrast ratios measured for every colour in the design system rather than estimated. Last evaluated September 2026.

Specific measures taken. All quiz and exercise controls are native HTML form elements, so keyboard behaviour comes from the browser rather than from custom scripting. Feedback is announced by moving focus to it rather than through a live region, which is more reliable across screen readers. Correct and incorrect states are conveyed by text and icon as well as colour. Answered questions remain reachable by keyboard so they can be reviewed. There are no time limits anywhere in the module.

Known limitations. The quiz requires JavaScript; all seven content sections and the summary page work fully without it. The site is light-theme only and does not yet offer a dark theme. Screen reader testing has been carried out with VoiceOver and Safari but not yet with JAWS.

Reporting a barrier. If any part of this module is difficult or impossible for you to use, we want to know and we will fix it. Contact us through Ask a Librarian, which reaches a monitored queue rather than an individual.

Content, sources and corrections

Written by UNLV University Libraries, September 2026. The curriculum draws on the ACRL Framework for Information Literacy for Higher Education, the ACRL AI Competencies for Academic Library Workers, the UNESCO AI Competency Framework for Students, and the ALA Code of Ethics.

This material dates faster than almost anything else the Libraries publishes. Every page carries a “last reviewed” date and the module is on a six-month review cycle. We deliberately describe capabilities rather than naming model versions, because capabilities age in years and version numbers age in weeks.

If something here is out of date or wrong, please tell us through Ask a Librarian.

Reuse

Headings are set in Outfit by the Outfit Project Authors, used under the SIL Open Font License and served from this site rather than from a font CDN. Body text uses whatever sans-serif your device already has, which is why no font has to be downloaded for it.

The instructional content is licensed CC BY 4.0 — you may share and adapt it, including for your own institution, with attribution. The underlying code is MIT licensed. The source is on GitHub, and the content lives in plain JSON files that can be edited without touching any code.

If you adapt this for another institution, the parts you will most need to change are the references to UNLV-licensed tools in Section 4 and the campus policy links throughout.
